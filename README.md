# todo

Prerequisites:
- Node 24
- npm

To run locally:

1. Git clone https://github.com/steskalc/todo.git
2. Run `npm install` at the project root, inside the `todo` folder.
3. In a terminal window at the project root, run `npm run dev` to start the Vite dev server.
    - Note the output localhost address (e.g "localhost:5173").
4. Navigate to the specified localhost address to view the app.

Hot reload is enabled, changes made to the app's `.vue` components should be immediately reflected in the browser.
